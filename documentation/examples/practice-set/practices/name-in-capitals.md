## Rule
Write my name in capitals wherever it appears — a byline, a signature, a
commit trailer, a slide.

## Detail

## Why
It is how I write it, and correcting it afterwards costs more than getting it
right the first time. There is no argument to have here: a personal set is
where a fact about one person lives, and this is one.

## Story
Raised in a session that had just fixed the same thing by hand for the fourth
time in a week. The fourth time is what made it a practice rather than an
annoyance.

## Install
Nothing to install. It applies wherever its owner works, because the personal
set travels with the person rather than with the project.
