## Rule
**If a script, or a run of under an hour, answers the question, run it before anyone reasons toward the answer.** An estimate made by ratio, by scaling a neighbouring figure or from memory of what a script does is labelled a placeholder wherever it appears, and cannot land as a result. **Read the rule out of the script; never infer what it does.**

## Detail
The estimate feels free and the run feels slow, and that is backwards once more than one session is waiting on the answer. Each estimate invites a counter-estimate, and each round re-plans the work downstream.

**A placeholder is allowed and is named.** Work that cannot wait may proceed on one, stamped as such, and is rebuilt when the run lands.

**What a script does is in the script.** A session that remembers a script as counting one thing when it counts another will argue confidently from the wrong rule. Opening the file costs a minute.

## Why
An argument from ratios cannot be settled by a better argument from ratios. Only the run settles it, and the run was available the whole time.

## Story
2026-11-24, in a project worked by many sessions at once. One question about a design's shape swung four times in two hours as sessions estimated it from ratios. The run that answered it took fifteen minutes.

## Install
Nothing to install. A session about to send an estimate asks first whether a script already answers it.
